# Запуски, имена прогонов и табличные данные

## 1. Имена каталогов прогонов

GUI создаёт каталог в `runs/` по шаблону:

```text
runs/<сценарий>_<ГГГГММДД>_<ЧЧММСС>
```

Например:

```text
runs/demo_20261111_121500
runs/topology_20261111_122000
```

Имя сразу показывает, какой сценарий выполнялся. Внутри лежат `config.ini`
и CSV-отчёты; при повторном запуске в ту же секунду добавляется суффикс
`_1`, `_2`.

Архивные результаты находятся в `results/experiments/<имя>`. Имена каталогов
там соответствуют содержанию:

| Каталог | Что внутри |
|---|---|
| `base_topology` | сравнение пяти топологий, базовые параметры |
| `stress_topology` | сравнение топологий в режиме перегрузки |
| `base_timeseries` | временные ряды пяти топологий |
| `sweep_lambda` | зависимость метрик от интенсивности атак |
| `sweep_resources` | зависимость метрик от ресурсов |
| `strategy` | FIFO/Triage при разных R |
| `attack` | векторы атак по топологиям |

| Сценарий | Динамика | Топологии | Sweep | Атаки | FIFO/Triage | Структура | Сводка | Данные |
|---|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|

| **`demo`** | **✓** | **✓** | **✓** | **✓** | **✓** | **✓** | **✓** | **✓** |
| `all` | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

**`demo` — рекомендуемый сценарий для проверки всех возможностей сразу.**
Он использует компактные параметры (5 прогонов Монте-Карло, T = 60,
5 топологий, два параметра sweep) и заполняет все вкладки примерно за
1 минуту. `all` делает то же самое, но с текущими пользовательскими
параметрами и может занимать значительно больше времени.

Запуск демонстрации:

```powershell
.\x64\Release\netsim.exe run --scenario demo --out runs\demo_example --progress
```

или в GUI: **Сценарий → «Демонстрация (все вкладки)» → Запустить**.

## 3. Что означает каждый CSV

| Файл | Содержимое | Вкладка GUI |
|---|---|---|
| `timeseries_<topo>.csv` | LCC, φ_w, E_phys, E_QoS, Q, IPTD, IPLR по времени | Динамика |
| `topology_comparison.csv` | средние и 95 % ДИ по топологиям | Топологии |
| `topology_significance.csv` | попарные тесты Манна–Уитни, поправка Холма | Топологии |
| `sweep_<param>.csv` | метрики от λ, R, μ, P_attack или трафика | Sweep |
| `attack_vector_analysis.csv` | targeted / random / cascading | Атаки |
| `strategy_comparison.csv` | FIFO/Triage, p-значения, исчерпание ресурсов | FIFO/Triage |
| `topology_structure.csv` | степени, кластеризация, L, D, r, γ | Структура |
| `topology_degrees_<topo>.csv` | гистограмма степеней | Структура |
| `run_meta_<topo>.csv` | E0, атаки, ремонты, очередь | Данные |

## 4. Сводные таблицы

Вкладка **«Сводка»** показывает только ключевые метрики в читаемом виде.
Набор таблиц зависит от прогона:

| Таблица | Колонки | Зачем нужна |
|---|---|---|
| Топологии | Топология, LCC, φ_w, E_QoS, Q, IPTD, IPLR | сравнить итоговую живучесть и QoS |
| Sweep: λ / R | x, Топология, LCC, φ_w, E_QoS, Q | увидеть порог и насыщение |
| FIFO/Triage | R, Топология, LCC/φ_w/E_QoS FIFO и Triage, p(φ_w), значимость | оценить эффект приоритизации |
| Атаки | Стратегия, Топология, LCC, E_QoS, φ_w, Q, IPLR | сравнить векторы атак |
| Временные ряды | Метрика × топологии: LCC, E_QoS, φ_w, Q, IPTD, IPLR, первый отказ, ресурсы, восстановления, очередь | интегральная сводка одной реализации |
| Структура | Топология, ⟨k⟩, k_max, CV, C, L, D, r, γ | объяснить различие ER/BA |

p(φ_w) — U-критерий Манна–Уитни; «Triage > FIFO» означает значимое
преимущество при p < 0,05. Доверительные интервалы и полные p-значения
остаются в CSV и доступны на вкладке «Данные».

## 5. Полные данные и перенос в отчёты

На странице «Результаты» есть вкладка **«Данные»**:

1. выберите CSV-файл в выпадающем списке;
2. таблица покажет все числовые значения;
3. **«Копировать»** копирует таблицу в буфер обмена в формате TSV —
   вставляется в Word/Excel с сохранением столбцов;
4. **«Экспорт CSV»** сохраняет таблицу в CSV с разделителем `;` и BOM
   UTF-8 (корректно открывается в русском Excel).

Кнопка **«Таблица»** на вкладках «Динамика», «Топологии», «Sweep», «Атаки»,
«FIFO/Triage» и «Структура» открывает соответствующую **сводную** таблицу.
Кнопка **«Таблицы»** в правом верхнем углу открывает вкладку «Сводка».

Это позволяет переносить в отчёт:

- средние и доверительные интервалы по топологиям;
- p-значения и направления значимых различий;
- значения E_QoS, Q, LCC, φ_w, IPTD, IPLR;
- параметры структуры ER/BA (k_max, CV, L, D, r, γ);
- временные ряды для построения собственных графиков.

## 5. Быстрая проверка

1. Запустите `demo`.
2. Дождитесь завершения — GUI автоматически откроет результаты.
3. Проверьте все вкладки: они должны быть заполнены.
4. Откройте «Данные», выберите `topology_comparison.csv`, нажмите
   «Копировать» и вставьте в Word — таблица появится с заголовками.
5. Для отчёта используйте `results/experiments/...` или свежий
   `runs/demo_<timestamp>`.
